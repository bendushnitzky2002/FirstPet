FirstPet Prototypes

FirstPet is a readiness check for first-time pet adopters. We built three prototypes, each testing a different hypothesis with a different persona. Pick one and click through, no tour needed.

A

Shared Check

Persona: Priya and Marcus, first-time adopters with two kids.

Hypothesis: A couple will finish the check together if one person can start alone and invite the other by link.

Try: Start a check as Priya, then open the invite as Marcus.

B

The Number

Persona: Vicky's future clients, owners who want the cost first.

Hypothesis: Leading with a local first-year cost and emergency cushion moves the skeptic from "no" to "ready once X changes."

Try: Enter a ZIP code and see the number before anything else.

C

Shelter Hand-off

Persona: Carla, a shelter adoption counselor.

Hypothesis: Adopters will finish the check when a shelter asks for it as step one, and counselors will use the summary and week-two check-in.

Try: Complete the check as an adopter, then view the counselor summary.
